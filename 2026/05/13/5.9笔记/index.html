信息收集一些想法

第一阶段：被动信息收集

1 域名与子域名全量收集

搜索各学院域名：domain="*.fafu.edu.cn" && title="学院"

搜索部门域名：domain="*.fafu.edu.cn" && title="处" || title="部"

搜索实验室域名：domain="*.fafu.edu.cn" && title="实验室"

搜索学生系统：domain="*.fafu.edu.cn" && title="学生" || title="教务"

2 IP 地址与网段收集

域名批量解析

ASN 查询

WHOIS 反查

IP 段归属验证

3 组织架构与人员信息收集

官网信息提取

搜索引擎搜索：site:fafu.edu.cn "教授" "邮箱"、site:fafu.edu.cn "电话"

学术平台搜索

社交媒体搜索 **（公众号，小程序）**

4 泄露信息收集

Github 搜索："fafu.edu.cn" password、"fafu.edu.cn" key、"fafu.edu.cn" secret

网盘搜索：在百度网盘、阿里云盘等平台搜索 “福建农林大学” 相关文件

浏览器搜索

第二阶段：主动信息收集

端口扫描与服务识别

重点端口关注：

  • 80 / 443：Web 服务
  • 21/22：FTP/SSH 服务
  • 3306：MySQL 数据库
  • 1433：SQL Server 数据库
  • 5432：PostgreSQL 数据库
  • 6379：Redis 数据库
  • 27017：MongoDB 数据库
  • 3389：远程桌面服务
  • 8080/8081/9000：常见 Web 应用端口

Web 应用指纹识别

使用多种工具交叉验证，提高指纹识别准确率

目录与文件扫描

使用多种字典和工具进行扫描，提高发现率

JS 文件分析

JS 文件是敏感信息泄露的重灾区，需重点分析

第三阶段：漏洞扫描
