一、服务器的搭建

首先得下载他的专门服务器

之后启动一次之后，查看他的本地文件

之后会进入一个 U3DS 的文件夹打开 serves 文件夹，进入 defuault 文件夹，再进入 serve 文件夹，打开里面的 Commands.dat

这里分享几个常用设置

之后回退到 u3ds 文件夹，将 unturned.exe 创建快捷方式，打开快捷方式的属性，在目标后面加上

点击确认

其实一个最基本的服务器就已经搭建好了，但是此时如果进不去服务器，可能需要 steam 服务器令牌

访问steamcommunity.com 创建对应 steam 令牌，填写在之前的 common.dat 中即可（注意 unturned 的游戏是 304930），之后也可以 config.txt 中的 login token 那填入令牌（详细配置可看后文相关部分），此时通过快捷方式就可以正常运行我们的服务器，运行服务器时请保证对 steam 的稳定链接

服务器打开后会有一个 sever code，将其复制给好友，让好友在游戏中输入即可

此时便可联机了，建议主机要好一点，其余细节可观看 b 站视频 2024 超详细的 Unturned 联机教程_哔哩哔哩 bilibili_未转变者_攻略

二、创意工坊

配置完服务器后，接下来就是添加创意攻防的地图

先打开 WorkshopDownloadConfig.json，在 default 文件夹内

注意 File_IDs，我们将在这里添加创意工坊地图

这里以 California2 为例，在 steam 中的创意工坊中找到相应项目，打开。

注意左上角的 url，https://steamcommunity.com/sharedfiles/filedetails/?id=3707778928

3707778928 就是要填写在 File_IDs 中的

加州还有一个配套的资源包，也需要下载，重复上述步骤，每个 id 用 , 隔开

保存好文件之后，运行服务器，就可以成功加载加州 2。可参考视频 Unturned 如何联机加利福尼亚 2.0_未转变者

三、修改 config

我们配置的服务器时可以修改 config 的，打开 config.txt

这里给出相关修改信息，只要在文件中一一对应即可

* 一、Browser — 服务器列表显示 *

* 配置选项 * * 说明 * * 默认值 / 难度差异 *
Icon 服务器大厅左上角显示的 64x64 图标 URL 无默认值
Thumbnail 服务器列表中显示的 32x32 缩略图 URL 无默认值
Desc_Hint 服务器大厅中服务器名下方的简短描述 无默认值
Desc_Full 服务器大厅右下方的详细描述 无默认值
Desc_Server_List 服务器列表中服务器名下方的简短描述 无默认值
Login_Token Game Server Login Token 在 steamcommunity.com/dev/managegameservers 生成 无默认值
BookmarkHost 广告的 IP / DNS / Web 地址 无默认值
Is_Using_Anycast_Proxy 是否使用 Anycast 代理 如果为 true，服务器大厅会警告游戏内延迟可能更高 默认: False
Monetization 服务器货币化方式 可选: Unspecified / Any / None / NonGameplay / Monetized 默认: Unspecified
Links 服务器大厅显示的链接按钮（JSON 数组格式） 无默认值

* 二、Server — 服务器核心设置 *

* 配置选项 * * 说明 * * 默认值 / 难度差异 *

Bad_Packet_Rate_Limit_Threshold 坏包速率限制阈值（次数） 超过此数量拒绝连接 默认: 10

Enable_Update_Shutdown 检测到新版本时自动关服 默认: False
Update_Steam_Beta_Name 更新检查的目标分支名称 默认: public
Update_Shutdown_Warnings 更新关服警告倒计时列表 格式同 Scheduled_Shutdown_Warnings 默认: 从 3 分钟开始倒计时
Chat_Always_Use_Rich_Text 聊天始终使用富文本（已无效，保留用于兼容） 默认: False
Validate_EconInfo_Hash 是否验证 EconInfo.json 哈希 默认: True
Use_FakeIP 是否使用 Fake IP 详见官方文档 默认: False
